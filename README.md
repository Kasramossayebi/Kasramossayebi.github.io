# Kasra Mossayebi - Academic Website

This repository contains the source for [kasramossayebi.github.io](https://kasramossayebi.github.io), the academic website of Kasra Mossayebi, a mathematics undergraduate at the University of Toronto.

The site highlights research in higher algebra, homotopy theory, Hodge theory, algebraic K-theory, mathematical physics, and quantum information. It includes dedicated pages for research, publications, talks, and a current CV.

## Updating the site

- Biography and homepage: `_pages/about.md`
- Research overview: `_pages/research.md`
- Talks: `_pages/talks.md`
- Publication records: `_bibliography/papers.bib`
- Web CV data: `_data/cv.yml`
- Downloadable CV: `assets/pdf/cv.pdf`
- Contact and researcher profiles: `_data/socials.yml`

The site is built with [Jekyll](https://jekyllrb.com/) and [al-folio](https://github.com/alshedivat/al-folio), then deployed to GitHub Pages through GitHub Actions. See `docs/` for the theme's development and customization documentation.
